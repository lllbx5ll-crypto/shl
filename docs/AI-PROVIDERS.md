# إعداد محركات الذكاء الاصطناعي في ZYQMORA

يعمل مولّد المواقع عبر فريق من المحركات المتخصصة، وليس نموذجاً واحداً:

- **Gemini 3.8 Flash**: تخطيط الهوية ومراجعة التصميم.
- **Groq Qwen 3.8**: كتابة الواجهة والوظائف بسرعة.
- **OpenRouter Free**: محرك احتياطي للنماذج المجانية، مع اختيار نموذج مختلف حسب المهمة.
- **Cloudflare Workers AI**: محرك احتياطي موجود في المشروع حالياً.

تعمل كتابة CSS وJavaScript بالتوازي بعد اكتمال HTML. إذا رفض مزود الطلب أو وصل إلى حد الاستخدام، ينتقل النظام تلقائياً إلى المزود التالي.

## إضافة مفاتيح API المجانية

من لوحة Cloudflare افتح Pages ثم مشروع zyqmora-ai ثم **Settings → Variables and Secrets**. أضف المفاتيح التالية كـ **Secrets / Encrypted** في بيئتي Production وPreview:

| Secret | مكان إنشاء المفتاح |
|---|---|
| GEMINI_API_KEY | https://aistudio.google.com/app/apikey |
| GROQ_API_KEY | https://console.groq.com/keys |
| OPENROUTER_API_KEY | https://openrouter.ai/settings/keys |

لا تضع المفاتيح داخل ملفات React أو GitHub أو في متصفح المستخدم. لا تحتاج إلى إضافة أي متغير إذا لم ترغب في تفعيل مزود بعينه؛ سيستخدم النظام المحركات التي تم ربطها فقط. احتفظ بربط Workers AI الموجود في wrangler.toml.

بعد إضافة أو تغيير Secrets أعد نشر Cloudflare Pages حتى تصل القيم إلى Functions.

## حدود الاستخدام المجاني

- Gemini API يوفر فئة مجانية لبعض النماذج، لكن حدود الطلبات تختلف حسب النموذج والمشروع، وقد تُستخدم بيانات الفئة المجانية لتحسين خدمات Google.
- Groq يوفر فئة مجانية بمعدلات محددة لكل نموذج؛ تحقق من صفحة Limits في حسابك لأن الحصة تتغير.
- OpenRouter يوفر نماذج مجانية، وخطة الاستخدام المجاني محدودة حالياً إلى 50 طلباً يومياً، مع حدود أخرى لكل نموذج.
- Cloudflare Workers AI يضم حصة مجانية يومية مقدارها 10,000 Neurons، وبعض النماذج تتطلب فوترة مفعّلة.

لا توجد حصة مجانية غير محدودة أو ضمان استمرارها. عند استنفاد حصة مزود ما، يحاول النظام استخدام مزود آخر متاح.

## نشر قواعد Firestore

كان حفظ المشروع يفشل لأن الواجهة ترسل الحقل designStyle بينما قواعد Firestore لم تسمح به. تم تصحيح firestore.rules. يجب نشر القواعد المحدثة إلى مشروع Firebase zyqmora-ai مرة واحدة:

```bash
npx firebase-tools deploy --only firestore:rules --project zyqmora-ai
```

تأكد من تسجيل الدخول إلى Firebase CLI بحساب يملك صلاحية نشر القواعد. نشر تطبيق Cloudflare Pages لا ينشر قواعد Firestore تلقائياً.

## ملاحظة عن FreeLLMAPI

FreeLLMAPI مشروع مفتوح المصدر لتشغيل راوتر محلي ذاتي الاستضافة، ويجمع مفاتيح مزودين عدة خلف نقطة API واحدة. لكنه يصف نفسه بأنه للاستخدام الشخصي والتجارب، ويحذر من كشف الراوتر على الإنترنت؛ لذلك لا نستخدمه كخدمة مشتركة عامة داخل ZYQMORA. نستخدم محولات مباشرة للمزودين بدلاً من تعريض مفاتيح المستخدم أو خادم راوتر شخصي.
