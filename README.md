## الخطة الافتراضية: تشغيل مجاني بدون API مدفوع

المشروع يحتوي حالياً على واجهة مجانية لإنشاء قوالب مواقع HTML/CSS/JavaScript ومعاينتها وحفظها في Firestore.

- **قالب فوري مجاني**: يصنع قالباً من الوصف بقواعد برمجية، يعمل على الأجهزة العادية، وليس نموذجاً ذكياً.
- **دردشة وتوليد بالذكاء الاصطناعي داخل المتصفح**: باستخدام [WebLLM](https://github.com/mlc-ai/web-llm) مع نماذج SmolLM2 مفتوحة الأوزان. تحتاج أجهزة الزوار إلى دعم WebGPU وموارد ذاكرة مناسبة وتحميل النموذج أول مرة (مئات الميجابايت أو أكثر).
- **بدون Puter**: لا حساب Puter ولا تكلفة تنتقل إلى المستخدم ولا API Key مزود ذكاء اصطناعي.
- **Firebase**: تسجيل دخول Google وقاعدة Firestore لحفظ مشاريع كل مستخدم.
- **Ollama اختياري لاحقاً**: تبقى ملفات `server/index.js` و`docker-compose.yml` موجودة، لكن الموقع لا يستدعيها في وضعه الافتراضي.

### تنبيه مهم

هذا حل للتجربة بميزانية صفرية من جهة تكلفة استدلال الذكاء الاصطناعي، **وليس ضمان تشغيل مجاني للأبد أو بلا حدود**. Firebase Hosting وFirestore لهما حصص مجانية، وملفات النماذج تُحمَّل من خدمة خارجية وقد تتغير حدودها. بعض المتصفحات لا تدعم WebGPU، كما أن النماذج الصغيرة أقل قدرة من خدمات البرمجة السحابية الكبيرة.

## ما نُفّذ في GitHub
- واجهة React/Vite عربية متجاوبة مع الجوال.
- صفحة «الذكاء الاصطناعي» الافتراضية تستخدم WebLLM محلياً بدلاً من Puter أو Ollama.
- نموذج SmolLM2 360M الخفيف، ونموذج SmolLM2 1.7B أثقل.
- زر «قالب فوري مجاني» حتى عندما يكون WebGPU غير متاح.
- معاينة ملفات الموقع داخل iframe معزول وCSP يمنع الاتصال الشبكي من المعاينة.
- حفظ مشاريع المستخدمين الخاصة في Firestore.
- إعداد مشروع Firebase `zyqmora-ai` دون تضمين Service Account في GitHub.
- ملفات Ollama محفوظة لتشغيل ذاتي مستقبلي اختياري.

## التشغيل والبناء

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

لتكوين النسخة التي توضع على الاستضافة:

```bash
npm run build
```

## خطوات الاستضافة

1. تأكد من نشر قواعد `firestore.rules` في Firebase Console.
2. تأكد من Google في Authentication > Sign-in method، وأضف اسم نطاق الموقع المنشور في Authorized domains.
3. انشر مجلد `dist` في Firebase Hosting بعد تنفيذ البناء، أو استخدم Firebase CLI وفق `firebase.json`.

أمثلة أوامر النشر بعد تسجيل الدخول إلى Firebase CLI:

```bash
npm run build
firebase deploy --only hosting
```

لا حاجة لخادم Ollama في النسخة الافتراضية. ومع ذلك يبقى تشغيل الموقع على استضافة فعلية إجراءً منفصلاً عن كتابة الكود في GitHub.
